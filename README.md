# mindows

Windows 11 작업 표시줄을 숨기고, macOS 스타일의 상단 메뉴 바와 하단 Dock으로 대체하는 WPF 앱입니다.

## 실행

```bash
dotnet run -c Release
```

종료는 메뉴 바의 로고 메뉴 → **Mindows 종료**를 사용합니다. 종료 시 작업 표시줄과 자동 숨기기 설정이 원래대로 복원됩니다.

프로세스가 강제 종료되어 작업 표시줄이 돌아오지 않으면 다음 명령으로 복원합니다.

```bash
dotnet run -c Release -- --restore
```

## 기능

**메뉴 바**
- 로고 메뉴: 이 PC에 관하여, 시스템 설정, 작업 관리자, 잠자기, 재시동, 시스템 종료, 화면 잠금, 로그아웃, Windows 작업 표시줄 보기(트레이 아이콘 접근용), Mindows 종료
- 현재 앱 이름(굵게): 가리기, 기타 가리기, 종료
- 윈도우 메뉴: 최소화, 확대/축소, 닫기, 앱의 창 목록
- 오른쪽: 배터리, 빠른 설정(Win+A), 검색(Win+S), 시계(Win+N 알림 센터)

**Dock**
- 고정 앱과 실행 중인 앱, 실행 표시 점, 휴지통
- 마우스 위치에 따른 확대 효과와 이름 라벨, 실행 시 튀어오르는 애니메이션
- 클릭: 실행하거나 앞으로 가져오기(이미 앞에 있으면 다음 창으로 순환)
- 우클릭: 창 목록, Dock에 유지, 파일 위치 열기, 종료 / 휴지통 열기·비우기

메뉴 바와 Dock은 셸 AppBar로 등록되므로, 최대화한 창이 두 영역을 가리지 않습니다.

## 설정

`%APPDATA%\Mindows\config.json`에서 Dock 고정 앱을 편집할 수 있습니다. `Path`에는 exe 경로나 `shell:AppsFolder\<AUMID>`를 지정합니다.
오류가 발생하면 같은 폴더의 `crash.log`에 기록됩니다.

## 제한 사항

- 주 모니터만 지원합니다.
- 시스템 트레이는 대체하지 않습니다. 트레이 아이콘이 필요하면 로고 메뉴의 **Windows 작업 표시줄 보기**를 사용합니다.
- 앱별 전역 메뉴(파일/편집/보기 등), Mission Control, Launchpad, Spotlight, Dock 드래그 정렬, 자동 시작은 구현하지 않았습니다.
- 테마(라이트/다크)는 시작할 때 한 번만 읽습니다.
